## 2. Bug Markdown legacy Telegram (ditemukan & diperbaiki saat audit)

Pola yang **terbukti merusak** pengiriman (HTTP 400 `can't parse entities`):
- underscore telanjang berpasangan dengan underscore di dalam code span (`/pdf_rekap` dsb.)
- code span `` `...` `` di dalam segmen italic `_..._`

**Fix:** semua command ber-underscore dibungkus backtick; italic tidak memuat code span.
Perbaikan menyentuh: tips rekap, `/help` semua role, pesan penolakan akses, daftar tiket,
notifikasi tiket (`kode_mesin` seperti `GENSET_02` kini aman).

**Guard permanen:** `tests/Feature/TelegramMarkdownSafetyTest.php` — mensimulasikan
parsing Markdown legacy untuk semua pesan × 5 role.
